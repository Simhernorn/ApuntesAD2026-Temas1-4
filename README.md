# Acceso a Datos · Materiales

Apuntes sencillos y programas de ejemplo basados en las cuatro unidades de la asignatura.
Cada unidad contiene una carpeta `docs` con explicaciones y una carpeta `ejemplos` con
programas comentados.

| Unidad | Contenido |
| --- | --- |
| [UD01 · Acceso a ficheros](UD01_Acceso_a_ficheros/docs/01_conceptos.md) | Texto, propiedades, datos binarios, acceso aleatorio y serialización. |
| [UD02 · Acceso a ficheros XML](UD02_Acceso_a_ficheros_XML/docs/01_conceptos.md) | DOM, XPath, recorrido y escritura de XML. |
| [UD03 · Acceso a bases de datos](UD03_Acceso_a_base_de_datos/docs/01_conceptos.md) | JDBC, CRUD, rutinas almacenadas e imágenes BLOB. |
| [UD04 · Patrones y librerías](UD04_Patrones_de_diseno_y_librerias/docs/01_conceptos.md) | Singleton, POJO/DTO, DAO, MVC, inyección de dependencias y Lombok. |
